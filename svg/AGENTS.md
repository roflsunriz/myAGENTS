# SVG 制作の AGENTS.md

## 目的と適用範囲

リファレンス画像を基に SVG を制作・修正するときは、「似ていると思う」という印象だけで進めず、観察、測定、描画、レンダリング、比較、修正を繰り返す。ユーザーが指定した再現度を、実際に表示した成果物と比較記録で確認できる状態にする。

このファイルは SVG 向けの追加指針である。作業前に、対象プロジェクトの共通ルール（`COMMON-AGENTS.md` 等）、ローカル `AGENTS.md`、このファイルを全文読む。共通の作業規律は維持し、SVG 以外の作業へ本指針を一律に適用しない。

## 依頼の読み分け

| 指示 | 維持するもの | 主な検証方法 |
| --- | --- | --- |
| 「そっくりに作れ」「模写しろ」「トレースしろ」 | 指定対象の構図、ポーズ、シルエット、部位の配置・形状・比率、線、色、陰影 | 同一座標での半透明重ね合わせ、輪郭比較、差分、主要点の位置比較 |
| 「キャラクターデザインを維持したまま、別のポーズ・表情で作れ」 | 体格、顔立ち、髪型、衣装、配色、固有の特徴と部位比率。描き方の変更指示がなければ参照の画風も継承する | 部位ごとの測定表、対応する向きでの形状比較、キャラクター全体の目視比較 |
| 「作風・画風を完全に維持したまま、別のポーズ・表情で作れ」 | 線、形の作り方、誇張・省略、比率の傾向、配色、陰影、質感、描き込み密度。同じキャラクターならデザインも維持する | 画風の特徴表、部位比率、全体と局所の比較 |

- ポーズや表情の変更は、その変更に必要な形状・重なり・見え方を変える指示として扱う。別人化、衣装変更、画風変更まで許可されたと解釈しない。
- 別キャラクターの制作が明示された場合は、画風の規則を新しいデザインへ適用する。元キャラクター固有の髪型や装飾まで無条件に移植しない。
- 「トレースして腕だけ上げる」のような依頼では、維持する領域を忠実再現として比較し、変更する領域を部位比率と画風で検証する。
- 言葉が混在していても、会話と参照から維持対象・変更対象を整理して進める。結果が大きく変わる矛盾だけを確認し、細部の分析をユーザーへ丸投げしない。

## 作業前に参照と完了条件を固定する

1. リファレンスの実画像を開く。ファイル名、説明文、記憶だけで描き始めない。複数枚ある場合は、デザイン、ポーズ、画風のどれを参照する画像かを整理する。
2. 対象領域、元画像の寸法、切り抜き範囲、背景・透過の扱い、SVG の `viewBox`、最終表示寸法を確認する。元画像を保存し、比較用の処理内容を記録する。
3. 維持する特徴、変更する箇所、識別上重要な部位、比較する代表点を短く記録する。複数の作例に差がある場合は、ユーザー指定の参照を優先し、平均して別デザインを作らない。
4. 参照の解像度、線幅、最終表示寸法、要求精度から、位置・輪郭・比率などの許容差と確認方法を先に定める。結果を見てから合格のために基準を緩めない。
5. 参照がない、隠れた部位がある、細部を判別できない場合は、観測できた事項と推定を分ける。見えない寸法を実測値として記載しない。主要なデザインを左右する不足は追加情報で解消し、それ以外は根拠のある推定を明記して進める。

## 忠実再現では制作途中から重ね合わせる

### 座標と表示条件をそろえる

- SVG を実際にレンダリングし、リファレンスと同じキャンバス寸法、対象領域、背景条件にそろえる。比較画像ごとに別の切り抜きや自動フィットをかけない。
- 座標対応は、原則として画像全体の平行移動と縦横比を保つ拡大縮小で定める。回転等が必要なら理由と変換を記録し、以後の比較で固定する。
- 画像全体を合わせた後に、顔、目、手などを別々に移動・変形してから合否判定しない。局所の位置ずれや比率の誤りが見えなくなる。
- 差を隠すための非等方拡大縮小、ワープ、過度なぼかし、都合のよい領域の除外を禁止する。背景を評価対象外にする場合も、その範囲を先に固定する。

### 描画と比較を反復する

1. 外形と大きな色面を描く。髪を含む全体シルエット、頭部、胴体、主要な手足の位置を優先する。
2. その時点の SVG をレンダリングし、参照と半透明で重ね合わせる。例えば参照上に SVG を不透明度 50% で重ね、必要に応じて不透明度を変える。
3. 全体の重ね合わせに加えて輪郭を別色で表示する、交互に切り替える、差分画像を作る等で、二重線、はみ出し、隙間、曲率の違いを確認する。比較画像は実際に開いて確認する。
4. 頭頂、顎、肩、関節、目の中心、髪の分岐、衣装の角など、対象に合う代表点の位置を比較する。外形だけでなく、内部の輪郭、部位同士の隙間、重なり順も合わせる。
5. 誤差の原因を、全体位置、スケール、部位比率、輪郭形状、線幅、塗り分け等に分け、対応する SVG の形状や属性を修正する。
6. 大形状、顔や手などの識別部位、線・色・陰影の各段階で再レンダリングと比較を行う。最後だけ重ねる運用にしない。
7. 最終修正・最適化後にも、提出する SVG から比較画像を再生成する。古いプレビューを検証結果に使わない。

### 誤差の読み方

- 輪郭は線の中心だけでなく、線幅を含む見える境界で確認する。滑らかに整えることで参照固有の角、歪み、非対称性を失わせない。
- 数値化する場合は、代表点の距離、輪郭間の距離、シルエットの重なり等を目的に応じて選び、座標系、対象領域、単位を記録する。画像全体の一致度だけで、小さな顔の誤りを合格にしない。
- アンチエイリアス、圧縮ノイズ、背景色の違いと、形状の誤りを区別する。差分画像がゼロであることを無条件に要求せず、描画条件の違いで本来の輪郭を歪めない。
- 数値が良くても、識別上重要な形や配置が異なる場合は修正する。未測定の一致率や「完全一致」を報告しない。

## ポーズ・表情変更では部位比率を抽出して適用する

### 部位を自律的に分解する

以下を出発点として対象画像を分析し、必要な項目を追加する。人型へ固定せず、動物、デフォルメ体型、複数の腕、尾、耳、角、翼、小物なども対象に合わせて扱う。写っていない部位へ測定値を捏造しない。

| 分類 | 観察・測定する主な関係 |
| --- | --- |
| 全身・ボディ | 頭身、頭部と胴体の大きさ、肩幅・腰幅、首の長さと太さ、胴の長さ、重心、胴体と脚の比率 |
| 頭・顔・髪 | 頭部と顔の縦横比、顔と髪全体の幅・高さ・面積の関係、生え際、前髪の位置、横髪・後ろ髪の張り出し、顎・頬・額の形 |
| 目・眉・鼻・口・耳 | 目の幅と高さの顔に対する比率、左右の目の間隔、目線の高さ、虹彩と白目の比率、眉との距離、鼻・口・耳の位置と大きさ |
| 腕・手 | 上腕と前腕の長さ、肩・肘・手首の位置、各部の太さ、手の大きさと顔の比率、掌と指の比率、指の描き分け方 |
| 脚・足 | 大腿と下腿の長さ、股・膝・足首の位置、太さの変化、足・靴の長さと幅、胴体や頭部に対する大きさ |
| 衣装・装飾・固有部位 | 襟、袖、裾、模様、アクセサリーの位置・寸法、髪束や耳・尾等の形と数、左右差、身体との接続位置 |

### 測定基準と根拠を記録する

- 基準長は、頭部の高さ、顔の幅、胴体の長さなど、その画像で判断しやすい部位から選ぶ。「頭部」は頭蓋相当か髪を含む外形か、「顔」は露出部分か推定した顔全体かを区別し、測る端点・範囲を定義する。
- 長さの比率は `部位の長さ / 基準長` として記録する。横幅と高さには適切な基準を別々に使ってよい。面積比を長さの比率と混同しない。
- 位置は画像全体の正規化座標と、顔の中心線・目線、肩・腰等を基準にした部位内の位置関係を使い分ける。目や口の配置を、画像の絶対ピクセル位置だけで保持しない。
- 測定表には「項目」「参照画像と測定箇所」「基準・測り方」「参照値または範囲」「観測／推定と不確実性」「制作側の値・対応」「差と判断」を残す。表は既存の制作メモや検証文書にまとめてよい。
- 実測値は、画像上で端点・境界・座標等を取得し、記録した測定方法から算出する。目分量の値は推定として扱う。一般的な人体比率、好みの頭身、別キャラクターの数値を、参照から得た比率の代わりに使わない。
- 複数の参照がある場合は、向きとポーズをそろえて解釈する。向きによる見かけの差を平均して体格と断定しない。

### 見かけの長さと維持すべき形を分ける

- 曲がった腕の肩から手首までの直線距離は、上腕・前腕の長さとは異なる。関節ごとの区間を分け、姿勢による変化と体格の変化を区別する。
- 斜め向き、遠近、短縮、隠れによって、画面上の長さや面積は変わる。単一画像から真の立体寸法を確定できるとみなさない。
- 正面の顔幅や両目の間隔を横顔へそのまま当てはめない。頭の向き、顔の中心線、面の回り込みを踏まえ、同じ頭部として整合するよう投影する。
- 笑顔、閉眼、開口等では、目や口の開き方、頬の形などが変わる。中立表情の輪郭を固定する代わりに、顔内の配置、造形の特徴、参照での表情の作り方を維持する。
- 参照にある誇張や非対称性を、標準的な解剖や左右対称へ勝手に矯正しない。推定する場合も参照の造形を優先する。

### 新しい構図へ適用して検証する

1. 要求されたポーズの骨格、関節、頭部・胴体の軸、支持点、重なり順を組み立てる。
2. 測定した部位比率を SVG の座標、寸法、描画パラメータ、ガイドへ反映して大形状を置き、向き・遠近・表情に必要な変化を加える。例えば同じ向きの目の幅は、制作側の顔幅に参照から求めた目幅比を掛けて求める。測定表を作っただけで、描画は目分量に戻す運用にしない。描きやすさのために手を小さくする、胴を伸ばす等の改変をしない。
3. 顔と髪、目と顔、手と頭部など、識別に強く影響する関係を先に確認する。その後に衣装、指、装飾、陰影を整える。
4. 参照と新しい SVG を並べて開き、全身と部位の拡大の両方で確認する。同じ向きの部位は、比較用の局所座標にそろえた重ね合わせも使える。
5. 向きやポーズが違う画像に、全身のピクセル一致を求めない。局所比較に使った変換を明示し、部位の形の検証と、全体の配置・比率の検証を分けて両方行う。
6. 部位比率の差が、要求された姿勢・投影・表情によるものか、意図しないデザイン変更かを記録して修正する。新しいポーズが成立し、維持対象も保たれるまで反復する。

## 作風・画風を比率だけで判断しない

| 観点 | 抽出して再適用する規則 |
| --- | --- |
| 線 | 外輪郭と内部線の太さの関係、強弱、先端・角の処理、線色、曲線の癖、途切れ方 |
| 形・省略 | 丸みと角の使い分け、誇張する部位、指・鼻・関節等の省略、左右差、髪束や服のしわのまとめ方 |
| 色 | 主色と差し色、明度・彩度の関係、線と塗りの関係、色面の割合 |
| 陰影 | 光の向き、影の段階数、境界の硬さ、影色、ハイライトの形、反射光やグラデーションの有無 |
| 質感・密度 | ベタ塗り、にじみ、かすれ等の表現、質感の粒度、余白、部位ごとの描き込み密度 |

- 対象画像から実際に観察できる特徴を短い特徴表にし、SVG のどの形状・線・塗りへ反映したか確認する。「アニメ風」「かわいい」等の分類語だけで済ませない。
- 部位比率が一致していても、線や陰影が異なれば画風の維持は未達として扱う。逆に配色だけを合わせて、顔やシルエットの違いを見逃さない。
- 参照にないグラデーション、光沢、輪郭線、装飾、質感を、仕上げや高品質化のつもりで追加しない。参照にある質感を、作りやすいベタ塗りへ無断で置き換えない。
- 新しいポーズでも、光源に対する面の向きに応じて影を描き直す。元画像の影の座標を貼り付けるだけにしない。

## SVG としての品質

- 主体の形状を、編集可能なパス、基本図形、グループ等で構成する。参照のラスター画像を `<image>` 等で貼り付けただけの成果物を、トレース済みの SVG として納品しない。
- 作業用の下敷き画像・補助線・測定点と納品する描画を分離し、提出する SVG が参照画像なしで意図どおり表示されることを確認する。ラスター併用が明示された依頼では、その範囲と依存を記録する。
- 自動トレースや生成ツールを使っても、出力をそのまま採用せず同じ測定・描画比較を行う。中間生成画像だけを正解にせず、ユーザーのリファレンスとの整合を確認する。
- 部位ごとに編集しやすい構造と命名を使う。不要なパス点、微小な断片、重複線を整理する際は、輪郭や線の表情が変わらないか再確認する。
- `viewBox`、描画範囲、クリッピング、塗り、透過、重なり順、外部画像・フォント等の依存を確認する。構文が正しいだけで表示も正しいと判断しない。
- 対象のブラウザまたは SVG レンダラーで、最終表示寸法と拡大表示を確認する。実際の埋め込み先がある場合は、そこでの表示も確認する。

## 完了条件と提出

次を満たしたことを、成果物と短い検証記録で確認する。

- 要求された構図、ポーズ、表情が成立し、維持対象のデザインと画風が保たれている。
- 忠実再現では、制作途中と最終版の重ね合わせを実施し、外形・内部輪郭・主要点の差を確認している。
- ポーズ・表情変更では、部位比率と画風の特徴を抽出・適用し、見かけの変化を考慮した比較を行っている。
- 最終 SVG 自体をレンダリングして目視確認し、最終修正後の検証画像と対応している。
- 最終 SVG、プレビュー、参照との比較画像、測定・画風の記録を利用者が確認できる。忠実再現では重ね合わせ画像も含める。既存の検証文書や比較シートへまとめ、同じ内容のファイルを増やしすぎない。
- 達成した精度、推定した箇所、残る差、未実施の検証があれば明示している。未達・未検証がある状態を「完全に維持」「検証済み」と呼ばない。

差が残る場合は、原因の特定と修正を続ける。画像の不足や描画環境の障害等で進められない場合は、確認できた根拠、代替検証、未検証の範囲、再開に必要な条件を示す。比較や修正をユーザー任せにして完了としない。
